# 四位角色动作补充

本轮只完善 Kimi、MiniMax、Claude、Codex。Qwen 保留草稿，不接入菜单。

## 使用

退出旧桌宠，重新双击项目根目录 `launch.vbs`。右键 → 换形象，现在包含鲸娘和上述四位。右键 → 动作预览，可以直接检查待机、开心、思考、工作、写文档、等你确认、睡觉、唤醒、轻戳和怕痒；预览约 6.5 秒后恢复状态跟随。睡觉/叫醒菜单适用于全部皮肤。

Kimi、MiniMax 使用已认可的短发 v2 普通表情；旧图以 `*-before-approved-v2.png` 保留。Claude/Codex 的原普通与开心立绘没有替换。

## 动作映射与边界

- 普通：使用原普通立绘；完成/双击/怕痒复用开心姿势。
- 思考：独立思考姿势；工作/写文档：独立键盘姿势，配合已有状态图标。
- 睡觉/打瞌睡/闭眼：独立闭眼姿势；唤醒：闭眼 → 普通两阶段过渡。
- Claude/Codex 等待使用独立抬手姿势；Kimi/MiniMax 等待复用思考姿势。
- 轻戳、拖拽、游动、音乐等复用现有姿势，加整数像素位移。27 个动作键均可加载，但没有宣称每个动作都具备独立逐帧原画。
- 沿用项目现有的 DSH/Claude 状态源。Kimi/MiniMax 的新增启动入口打开各自网页；本轮没有建立新的 Kimi/MiniMax Agent 状态接口，也没有新增 Codex 原生状态监听。

## 生成提示词记录

使用内置 image_gen。共同提示：透明 1024 方形 2×2 图集，四格同一人物、同一胸像尺度、独立状态姿势、粗方形像素、深色阶梯描边、无文字水印。参考现有普通/开心立绘，不参考 Qwen 草稿。

- Kimi：黑色短发、月牙、星月披肩；四格依次开心挥手、托腮思考、键盘工作、闭眼侧倚。
- MiniMax：粉色短发、双发夹、黑粉外套；开心 V 手势、托腮思考、键盘工作、闭眼侧倚。
- Claude：橙色长发、花饰黑蝴蝶结；托腮思考、键盘工作、闭眼侧倚、疑问抬手。
- Codex：银白长发、双龙角、紫眼白紫裙；托腮思考、键盘工作、闭眼侧倚、疑问抬手。
